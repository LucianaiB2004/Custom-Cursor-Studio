# 高清案例画稿与尺寸处理

四个角色均通过内置 `image_gen` 工具分别生成透明PNG，使用各自已有角色图片作为参考，没有将64px光标放大冒充新画稿。每套 `artwork/高清母版.png` 为项目内保留的原始生成结果（至少1024px边长）。原始参考文件保持不变；这是参考重绘版本，并非恢复原作者不存在的高清细节。

提示词均要求：单个完整角色、原有身份与配色、居中透明alpha背景、清晰原生高分辨率轮廓、全身不裁切、无文字水印、无光标箭头、适合缩小到64/96/128px。每套的角色约束如下：

- 懒羊羊：忠实经典白羊形象，头顶冰淇淋卷毛、短棕色羊角、肤色脸、大眼睛、小黑鼻、粉脸颊、张嘴笑、黄色口水巾、小羊身体、双手放在围兜处；清楚的2D动画描线、白/肤色/金黄配色，不做3D。
- 一二：保留原表情的白色圆熊、棕耳、粉腮、圆眼镜、黄色耳机、手捧蓝色打开的书、坐姿和小棕脚，修复像素边缘，保留简单贴纸比例。
- 吹泡泡Dva：以原像素光标中的角色与服装作参考，重绘棕长发、粉色脸颊标记、粉蓝白驾驶服、耳机、双手托脸、坐姿和嘴前粉色泡泡；去掉参考图独立的鼠标箭头。
- 月神天使：以原像素光标为参考重绘，保留长淡紫发、蓝紫眼、月亮头冠、白蓝紫服装、小羽翼、坐姿、月牙装饰和少量星光；去掉原光标箭头，平涂与少量赛璐璐阴影。

生成后人工查看四张结果，再由 `editor/scripts/build_hd_cases.py` 制作256px角色与功能符号画布。功能符号用于确定点击热点，不由AI猜测。96px工程保存256px素材与输出坐标热点，尺寸选择只改变输出尺寸和热点比例，直到最终导出才缩小像素；禁止先烘焙成64/96px再放大。

15种状态全部具有独立功能符号。正常选择、链接选择为四帧轻浮动；忙/后台运行用八帧旋转环，角色本体不是逐帧表情重绘。工程保留真实毫秒时长，ANI按1/60秒量化。每套有 `Windows主题/64`、`96`、`128`，以及对应ZIP。`theme-map.json` 的variants明确指定每个尺寸的15个文件，默认96。

应用入口同时设置 `CursorBaseSize`，不只替换光标路径。微软的MousePointer配置资源同样使用此值：[官方实现](https://github.com/microsoft/winget-dsc/blob/main/resources/Microsoft.Windows.Setting.Accessibility/Microsoft.Windows.Setting.Accessibility.psm1)。取消入口把15个角色路径置空并刷新，由Windows加载内置默认资源：[微软主题格式默认示例](https://learn.microsoft.com/en-us/windows/win32/controls/themesfileformat-overview)。

`editor/evidence/高清案例对照.png` 直接从交付CUR/ANI解码，不把预览显示倍数当作真实文件尺寸。Windows原生可加载性与后台事务有自动检查；未经用户点击确认不应用系统，真实桌面切换/取消仍需用户验收。
