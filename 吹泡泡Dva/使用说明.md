# 吹泡泡Dva

双击 `应用主题.cmd`，选择64/96/128像素后点击应用，改变全部15种系统指针。选择尺寸本身只更新预览，不修改系统。

取消自定义：运行项目最根目录的 `取消自定义光标.cmd`，恢复 Windows 默认白色指针及默认大小；不是切回之前的自定义主题。

直接使用仅需 Windows 10/11 自带的 Windows PowerShell，无需 Python、联网、管理员权限。请保留完整仓库目录，入口引用editor/scripts/use-theme.ps1。

应用前逐个检查原生文件，先备份当前用户设置，再复制光标到 LocalAppData 持久目录。不会执行原始 INF。备份位于 `%LOCALAPPDATA%/CustomCursorStudio/portable/backups`。

`放大与导出.cmd` 打开尺寸选择和实际鼠标试用窗口（默认96px），需要编辑器依赖。选择大小后须点击“应用所选大小”才切换系统。`编辑主题.cmd` 用于修改工程。`project/` 是可编辑工程；各尺寸均由高清母版生成，请勿把旧64px资源拉伸冒充高清版本。
